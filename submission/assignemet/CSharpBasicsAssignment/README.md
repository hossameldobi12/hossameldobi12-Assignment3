# CSharpBasicsAssignment

## About the Project

This project is a C# console application created to practice the basics of C# and understand how the language handles variables, types, operators, and memory.

Each part covers a specific topic with code examples, console output, and short explanations.

## Topics Covered

- **Part A — Project Structure:** Understanding project files, `.csproj`, `Program.cs`, `bin/`, `obj/`, and solution file formats.
- **Part B — Variables, Types & Casting:** Working with data types, implicit and explicit casting, boxing, `Parse`, `TryParse`, and `Convert`.
- **Part C — Value vs. Reference Types:** Understanding structs, classes, object references, and copying behavior.
- **Part D — Scope & Operators:** Practicing variable scope, compound assignment operators, and bitwise operators.
- **Part E — Stack & Heap:** Drawing memory diagrams to understand how objects and references work.
- **Part F — LeetCode 136: Single Number:** Solving a problem using the XOR (`^`) operator.
- **Part G — Short Answers:** Answering questions about project settings, code regions, XML documentation comments, and static fields.

## Technologies Used

- C#
- .NET 10
- Visual Studio

## How to Run

1. Clone or download the repository.
2. Open the project in Visual Studio, or open a terminal in the project directory.
3. Run the application using:

```bash
dotnet run
```
